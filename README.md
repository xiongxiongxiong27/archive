# 《档案学通讯》主题分析

对《档案学通讯》2024 年第 3、4、6 期共 40 篇论文摘要进行主题挖掘：
中文分词 → 停用词过滤 → TF-IDF 关键词提取 → LDA 主题建模（k=4/6/8，双随机种子稳定性对照），
并对每个主题回查原文例句，验证解释是否有证据支持。

## 主要发现
- TF-IDF 全域关键词：文书、档案学、技术、业务、要素、制度、政务、政策、共情、红色、刑罚等
- LDA 稳定复现六个语义簇：古文书与历史档案 / 档案法治 / 技术与政务数据治理 /
  共情传播与档案文化 / 档案数据要素与红色·科学数据 / 档案教育与人才培养
- 所有主题高权重词均能在原文摘要中找到直接例句，解释成立

## 文件说明
| 文件 | 内容 |
|---|---|
| `corpus.py` | 语料库（40 篇论文摘要） |
| `analyze.py` | 分词、停用词、TF-IDF、LDA 分析脚本 |
| `make_report.py` | 根据 results.json 生成 HTML 报告 |
| `report.html` | 最终分析报告（浏览器打开查看） |
| `results.json` | 模型原始输出 |
